Low-level quantum programming

Aspects of low-level quantum languages:

  • Classical (high-level) programs construct quantum circuits (AOT or JIT).
  • Strong separation, quantum is second-class.
  • Limited or no quantum control flow.
  • Very limited data abstraction (e.g., a single qubit register).
  • Manual resource allocation/deallocation/reuse.
  • Representation encourages losing information.
  • Representation encourages early commitment to specific implementation details.
  • Typically: Hand-rolled design automation.
  • …

High-level quantum programming

Aspects of high-level quantum languages:

  • High-level quantum programs perform the computation.
  • Uniform syntax and semantics. Classical is a special case of quantum.
  • Quantum control flow, beyond controlled gates.
  • Quantum data abstracted into first-class variables of the language.
  • Automatic resource management.
  • Representation encourages encoding intent / preserving information.
  • Representation encourages no/late commitment to specific implementation details.
  • Typically: Shared design automation infrastructure.
  • …

def bernstein_vazirani[n:!ℕ](const f: 𝔹^n !->lifted 𝔹){
	xs := [H(0) for _ in 0..n];
	if f(xs) { phase(π); }
	return measure([H(x) for x in xs]);
}

		r ⊕= bs[i]·xs[i];
	}
	return r;
}

QFT in Silq

def QFT[n:!ℕ](x: uint[n])mfree: uint[n]{
  for k in [0..n div 2){
    (x[k],x[n-k-1]) := (x[n-k-1],x[k]);
  }
  for k in [0..n){
    x[k] := H(x[k]);
    for l in [k+1..n){
      if x[k] && x[l]{
        phase(2·π·2^(k-l-1)); // 0-qubit gate
      }
    }
  }
  return x;
}

“Textbook” variant of Shor’s algorithm (for semiprimes)

import qft;

def main() {
  N := 3233; a := 10 coerce !ℤstar[n];
  n := 2·ceil(log₂(N))+1 coerce !ℕ;
  while true {
    t:=[H(0) for i in 0..n] as uint[n];
    measure(a^t);
    QFT(t) := t; // adjoint calls
    θ := (measure(t) as !ℕ)/2^n;
    for r in candidates(θ) {
      k := gcd(a^(r div 2)+1 as !ℕ,N);
      if 1<k && k<N { return k; }
    }
  }
}
def candidates(q:!ℚ): !ℕ[] {
  r := [];
  (b, d) := (1, 0);
  while q≠0 {
    q = 1/q;
    k := floor(q) coerce !ℕ;
    (b, d) = (k·b+d, b);
    if b>1 { r ~= [b]; }
    q -= k;
  }
  return r;
}

Iterative variant of Shor’s algorithm (for semiprimes; no explicit QFT)

def main() {
  n := 3233; a := 10 coerce !ℤstar[n];
  while true {
    (q, x) := (0, 1:!ℤstar[n]);
    for i in (2·ceil(log2(n))+1..-1..0] {
      bit := H(0);
      if bit {
        x ·= a^(2^i);
        phase(-2·π·q·2^i);
      }
      q += measure(H(bit))/2^(i+1);
    }
    measure(x);
    for r in candidates(q) {
      k := gcd(a^(r div 2)+1 as !ℕ, n);
      if 1<k && k<n { return k; }
    }
  }
}

  (b, d) := (1, 0);

    q = 1/q;
    k := floor(q) coerce !N;
    (b, d) = (k·b+d, b);
    if b>1 { r ~= [b]; }
    q -= k;
  }
  return r;
}

Amplitude Amplification

def amplify_amplitude[n:!N](
  const p: uint[n] !->lifted B,
  x: uint[n]
): uint[n] {
  if p(x) { phase(π); }

  with H_n(x) := x {
    if x != 0 {
      phase(π);
    }
  }
  return x;
}
def H_n[n:!N](x: uint[n]){
  for i in 0..n{ x[i] := H(x[i]); }
  return x;
}

def main() {
  def p(const x: uint[6]) => x == 42;
  x := H_n(0: uint[6]);
  repeat 6 {
    x := amplify_amplitude(p, x);
  }
  return x;
}

GQSP: Apply a bounded polynomial to a unitary.

def gqsp[d:!N](const P:!R^(d+1))[a:qtype](
  const f: a ->mfree a
)(x: a): B x a {
  (ts, ps, l) := compute_angles(P);
  anc := R(ts[0], ps[0], l)(0);
  for j in 1..d+1 {
    if anc = 0 { x := f(x); } // controlled
    anc := R(ts[j], ps[j], 0)(anc);
  }
  return (anc, x);
}

namespace Solution {
	open Microsoft.Quantum.Primitive;
	open Microsoft.Quantum.Canon;
    operation EvaluatePeriodClauses (queryRegister : Qubit[], periodAncillas : Qubit[]) : Unit {
        body (...) {
            let N = Length(queryRegister);
            for (period in 1 .. Length(periodAncillas)) {
                for (i in 0..N-period-1) {
                    CNOT(queryRegister[i + period], queryRegister[i]);
                }
                (ControlledOnInt(0, X))(queryRegister[0..N-period-1], periodAncillas[period-1]);
                for (i in N-period-1..-1..0) {
                    CNOT(queryRegister[i + period], queryRegister[i]);
                }
            }
        }
        adjoint auto;
    }
    operation Solve (x : Qubit[], y : Qubit) : Unit {
        body (...) { // Winter 2019 Q# coding contest master solution for problem C2
            let N = Length(x);
            using (anc = Qubit[N - 1]) {
                EvaluatePeriodClauses(x, anc);
                (ControlledOnInt(0, X))(anc, y);
                X(y);
                Adjoint EvaluatePeriodClauses(x, anc);
            }
        }
        adjoint self;
    }
}

def solve[n:!N](const x:B^n){
  y := 0;
  for p in [1..n){
    z := 1;
    for i in [0..n-p){
      z &= x[i]=x[i+p];
    }
    y |= z;
  }
  return y;
}

def main(){
  x := [H(0) for i in [0..3)];
  y := solve(x);
  return (x, y);
}

Automatic uncomputation

  • Static analysis detects quantum states of the form ∣φ,ψ⟩=∑x​∣x,f(x)⟩.
  • For such states, coherent dropping is realizable: ∣φ,ψ⟩↦∣φ⟩.
  • Each expression is either used as a control (const) or consumed (moved).
  • Silq coherently drops quantum information that is not consumed (when possible).
  • Type checker catches programming mistakes.
def f[n:!N](const x:uint[n])qfree: uint[n] { ... }

def main() {
  x := [H(0) for _ in 0..n] as uint[n];
  y := f(x);
  if y > 5 { phase(π); } // condition is uncomputed
  return x; // we don't return `y`; uncomputed
}

Example: Lifted Bitcoin EC Point Addition

p := 2^256-2^32-977 coerce !N;
a := 0, b := 7; // y^2 = x^3 + 7 (mod p)
Field := Zmod[p];
Group := Zstar[p];
APoint := B x Field x Field; // (infinity, x, y)

def affine_add(const P: APoint, const Q: APoint): APoint{
  (infinity1,x1,y1) := P;
  (infinity2,x2,y2) := Q;

  if infinity1{ return Q; } // early return under quantum condition
  if infinity2{ return P; } // early return under quantum condition

  if x1=x2{
    if y1=y2{
      return affine_double(P); // early return under quantum condition
    }
    return affine_infinity(); // early return under quantum condition
  }

  lam := (y2-y1)/(x2-x1 pun Group);

  x3 := lam*lam-x1-x2;
  y3 := lam*(x1-x3)-y1;

  return (false,x3,y3): APoint;
}

Quantum programming with isometries

  • Unitary operators require output qubits to be allocated up-front and all input qubits have to be returned.
def H_n[n:!ℕ](qs:𝔹^n):𝔹^n{ // unitary, n-qubit Hadamard transform
  for i in [0..n){
    qs[i] := H(qs[i]);
  }
  return qs;
}
  • Isometries can allocate qubits internally:
def entangle_H[n:!ℕ](q:𝔹):𝔹^n{ // isometry
  assert(n ≥ 1);
  return H_n([dup(q) for i in [0..n-1)]~[q]);
}

Partial Isometries (Unsafe)

  • Partial isometries can deallocate qubits in known states.
def dealloc_plus(x:B){ // partial isometry from B to unit
  H(0) := x; // adjoint of x := H(0)
}
  • This is unsafe, there is no deterministic way to check validity on a quantum computer.
  • However, the intent is made clear and therefore errors can be caught in a simulator.

Control and Scoping

  • There is both classical if and quantum if (ad-hoc polymorphism).
if measure(H(0)) { ... }

x := H(0);
if x{ ... } // note: `if H(0){ ...}` not valid
  • Variables can be declared conditionally in branches and escape them:
x := H(0);
if x{
  t := H(0);
  y := t;
}else{
  y := 1;
}
return (x,y);
  • Key benefit: This does not force a specific register allocation.

Updates as consume-then-declare

def main(){
  x := H(0);
  y := 0;
  if x{
    y := H(y);
  }
  return (x,y);
}

Uncomputation and Adjoint Synthesis Example

Recall we are working with Turing-complete, recursive programs.

def rec[n:!N][m:!N](const x:B^m,y:B^m)qfree:B^m{
  if n!=0{
    t:=vector(m,1:B);
    t:=rec[n sub 1](x,t);
    y:=f(t,y);
    forget(t); // (explicit for emphasis)
  }else{
    y:=f(x,y);
  }
  return y;
}

Naive Uncomputation Synthesis

def rec[n:!N][m:!N](const x:B^m,y:B^m)qfree:B^m{
  if n!=0{
    t:=vector(m,1:B);
    t:=rec[n sub 1](x,t);
    y:=f(t,y);
    rec[n sub 1](x,t):=t; // forget(t)
    vector(m,1:B):=t;
  }else{
    y:=f(x,y);
  }
  return y;
}

Keeping around the garbage

(Pseudocode)

def rec_g[n:!N][m:!N](const x:B^m,y:B^m, ref g:Garbage)qfree:B^m{
  if n!=0{
    t:=vector(m,1:B);
    t:=rec_g[n sub 1](x,t,g);
    y:=f(t,y);
    g.dispose(t);
  }else{
    y:=f(x,y);
  }
  return y;
}

Garbage-consuming adjoint

(Pseudocode)

def rec_g_adj[n:!N][m:!N](const x:B^m,y:B^m, ref g:Garbage)qfree:B^m{
  if n!=0{
    t:=g.pick[B^m]();
    f(t,y) := y;
    t := rec_g_adj[n sub 1](x,t,g);
    vector(m,1:B) := t;
  }else{
    f(x,y) := y;
  }
  return y;
}

rec with efficient uncomputation

def rec[n:!N][m:!N](const x:B^m,y:B^m)qfree:B^m{
  if n!=0{
    t:=vector(m,1:B);
    g:=empty_garbage();
    t:=rec_g[n sub 1](x,t,g);
    y:=f(t,y);
    t:=rec_g_adj(x,t,g); // rec_g[n sub 1](x,t,g) := t;
    empty_garbage():=g;
    vector(m,1:B):=t;

    y:=f(x,y);
  }
  return y;
}

Outlook

Some exciting things we are still working on:

  • “Error handling”: We cannot detect manual uncomputation errors in general, but we can conjugate by an isometry:
def amplify_amplitude[n:!N](
  const p: uint[n] !->lifted B,
  x: uint[n]
): uint[n] {
  if !p(x) { phase(π); }
  if H_n(0: uint[n]) := x { phase(π); }
  return x;
}

We are still thinking about how to best expose this in Silq. (C.f. arXiv:2507.11676)

  • Measurement-based uncomputation: Currently uncomputation in Silq is always adjoint-based.
  • Improved optimizer for general quantum functions (currently: focus on lifted).
  • Backends beyond OpenQASM (QIR, MLIR dialects, …, CudaQ?).

Summary

  • Silq: convenient developer/end-user interface to quantum computer.
  • HQIR: supports transformations that map Silq code to circuit-level.
  • qblaze: highly optimized sparse simulator, scales by avoiding hash tables.
  • Silq (including compiler to HQIR) and qblaze are available on GitHub with permissive licenses; HQIR coming soon (OOPSLA'24 artifact on Zenodo):
    https://github.com/silq-lang/silq · https://github.com/insait-institute/qblaze
