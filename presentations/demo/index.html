Live coding

Edit the highlighted Silq program and press Ctrl+Enter. Output appears on the right. Agda-style input works in the editor: type \bN for ℕ, \lambda for λ, or \ne followed by Space for ≠. Enter indents new lines and Tab reindents the current line using the same rules as silq-mode.el.

Authoring the next deck

  • Put the deck in content/presentations/.
  • Keep every slide in the same Markdown file.
  • Separate slides with a thematic break: --- on its own line.
  • Run the normal development script and open the deck URL.

That is the entire authoring model.
