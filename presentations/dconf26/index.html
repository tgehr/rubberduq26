def bernstein_vazirani[n:!ℕ](const f: 𝔹^n !→lifted 𝔹){
	xs := [H(0) for _ in 0..n];
	if f(xs) { phase(π); }
	return measure([H(x) for x in xs]);
}

def f(const xs:𝔹^5){
	bs := [0,1,0,1,1];
	r := 0;
	for i in 0..5{
		r ⊕= bs[i]·xs[i];
	}
	return r;
}

def main() => assert(bernstein_vazirani(f) == [0,1,0,1,1]);

Quantum: Interference

Example: Hadamard operator

H∣0⟩=∣+⟩=0.5​⋅∣0⟩+0.5​⋅∣1⟩
H∣1⟩=∣−⟩=0.5​⋅∣0⟩−0.5​⋅∣1⟩

Linearity holds generally, so we get interference:

H∣+⟩​=0.5​⋅H∣0⟩+0.5​⋅H∣1⟩=0.5​⋅∣+⟩+0.5​⋅∣−⟩=0.5⋅∣0⟩+0.5⋅∣1⟩+0.5⋅∣0⟩−0.5⋅∣1⟩=∣0⟩.​

Similarly, H∣−⟩=∣1⟩.

Application: Factoring Semiprimes (Shor’s Algorithm)

Input: N=p⋅q, for primes p,q
Output: p and q.

Classical Observations

It suffices to find 2≤a<N and even r with a^r%N = 1, a^(r/2)%N is not 1 or N−1.

Then: 0 = (a^r-1)%N = ( (a^(r/2)+1)%N * (a^(r/2)-1)%N ) % N

Therefore gcd(a^(r/2)+1, N) is a nontrivial factor of N.
